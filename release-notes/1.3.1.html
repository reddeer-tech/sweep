What's New in 1.3.1

Fixes

  • After a clean, Sweep no longer says Time Machine snapshots are holding your space when there are none, and when what you cleaned went to the Trash it says so, the space comes back once you empty the Trash
  • The note about Time Machine snapshots that followed every clean now only appears when snapshots are actually holding space
  • Removing Time Machine snapshots that macOS or you had already removed since the scan now counts as done instead of failed

Also in 1.3.0

A new look

Sweep now looks and feels like a Mac app. Every screen uses Apple's own SF Symbols instead of emoji, Settings is laid out like System Settings with grouped cards and small switches, Clean has a sidebar like Finder's with an icon for every section, and buttons, checkboxes, menus and tabs follow the macOS style in both light and dark mode

Fixes

  • When your Mac is too busy to measure its processes, the Memory and CPU lists now say so and offer Refresh, instead of showing an empty, broken page
  • Sweep Menu's icon now changes when Sweep updates. macOS kept showing the blank icon it had stored, so notifications from the menu-bar icon could still have a blank icon after 1.2.3
  • Settings and warnings that used fixed dark colours now follow light mode too

Also in 1.2.3

Sweep's icon on its notifications

Notifications from Sweep's menu-bar icon, like low disk space, Time Machine, memory and heat alerts, now show Sweep's icon instead of a blank one

Opening Sweep from the menu bar works again (1.2.2)

In 1.2.1, choosing Open Sweep, Scan My Mac, Quick Clean or Settings in the menu-bar menu, or clicking a low-disk notification, started Sweep without ever showing its window when Sweep was not already open, and later clicks did nothing. Sweep now opens every time

If a Sweep from 1.2.1 is stuck like that, Force Quit it (Option-click its Dock icon, or use Activity Monitor), then open Sweep again

Also in 1.2.1

In 1.2.0 the new menu-bar helper, Sweep Menu, could not start, and Sweep hid its own icon anyway, so there was no menu-bar icon at all. Sweep Menu now starts, and Sweep keeps its own icon whenever the helper is not actually running, so the icon is never missing again

Also new in 1.2.0

A much lighter menu bar

The menu-bar icon now comes from Sweep Menu, a small helper of about 13 MB that stays in the menu bar on its own, so Sweep itself quits when you close its window and gives all its memory back. Sweep Menu starts when you log in, asks once to send notifications, and shows up in System Settings under Login Items. If you switched on the clutter alert, the trashed-app alert or a schedule that runs while Sweep is open, Sweep keeps running in the background for those

When your Mac starts, only the menu-bar icon appears. Sweep itself no longer opens its window at login, it starts in the background only if an alert or schedule needs it, and otherwise not at all

Sweep Menu never deletes anything and reads nothing private, every item in its menu opens Sweep where you review and confirm as before

The watcher checks much more

On top of disk space, Time Machine, swap and temp folders, it now notices

  • An app or background process that keeps a CPU core busy for half an hour, and tells you when it has gone on for an hour
  • Memory that keeps growing without coming back, and tells you when it is heading for running out of memory
  • macOS running short of memory, naming the apps using the most
  • Your Mac running hot enough that macOS slows it down, and what is keeping it busy
  • A kernel panic or an out-of-memory restart since the last check, and background jobs stuck in a crash loop

Only the urgent ones send a notification, at most once a day each, the rest show in the menu and in Optimize ▸ Health. All of it comes from counters macOS already keeps, so a check costs a few milliseconds and nothing runs between checks

Fixes

  • A Time Machine backup that is slow but still counting changes is no longer reported as stuck, and a backup paused by sleep overnight no longer looks stuck in the morning
  • A notification about an app whose name has spaces in it no longer repeats at every check
  • "Filling fast" is measured over at least 50 minutes, so a big download or build that is deleted again soon no longer raises it
  • An old Time Machine backup no longer sends a daily notification when you turned automatic backups off yourself
  • Opening Sweep from a notification or from the menu now always brings back its Dock icon and window
  • A check skipped while Sweep was busy now runs a couple of minutes later instead of a whole interval later
  • Sweep follows the system's light or dark appearance without checking every two seconds
